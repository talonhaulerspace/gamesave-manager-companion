## About

GameSave Manager Companion helps you organize your game save backup strategy. Track backup schedules per game, document cloud sync configurations and maintain a log of critical save states across your game library.

---

## Features

| Feature | Description |
|---------|-------------|
| **Backup Schedule** | Plan and track backup frequency per game in GameSave Manager |
| **Save Profiles** | Document important save states with game progress notes |
| **Cloud Sync** | Track cloud backup destinations and sync status per game |
| **Recovery Log** | Log save recovery events and their cause for future reference |
